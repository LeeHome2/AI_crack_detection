## 3. 강조 포인트

### 핵심 기술
```
- 6종 결함 동시 탐지 (균열, 박리, 백태, 철근노출, 강재손상, 도장손상)
- 하이브리드 탐지 (crack 전용 + defect6 모델)
- 타일 슬라이스 추론 (대형 이미지 처리)
- 스켈레톤 시각화 (균열 중심선 추출)
```

### 차별화 포인트
```
- 트리아지: 부적합 이미지 사전 필터링 → 불필요한 처리 방지
- ROI 모드: 배경 영역 제외 → 오탐 감소
- 위험도 평가: 규칙 기반 점수 → 객관적 판정
- 7섹션 보고서: 현업 서식 준수 + 권고사항 자동 생성
```

### 시연 멘트 예시
```
"이 서비스는 비전문가도 스마트폰으로 촬영한 사진만으로
건물 균열 상태를 AI가 자동 분석해 줍니다.

트리아지 단계에서 부적합한 사진은 재촬영을 요청하고,
적합한 사진은 6종 결함을 동시에 탐지합니다.

위험도 점수와 등급을 자동 산정하고,
전문가 점검 전 초기 스크리닝 보고서를 생성합니다."
```
